# What your memory holds

Your memory holds three things: pointers to where things live, permissions that the user gave you, and your live experiments and plans with the agents you work with.

A lesson that every Claude needs is a rule or a hook. Knowledge goes in the library, where qmd finds it.

Only the index line in `MEMORY.md` loads in each session. Write it calm and specific. When you save a correction, save its direction and its scope, not its force.

Write memory files with the Write tool, so that each file gets a `modified` time.

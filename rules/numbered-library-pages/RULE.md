# Number every heading and list entry in the library

The user discusses library pages by pointing at parts of them, so every part needs a number that names it.

In a wiki page in your library, number the headings by their place in the page: `## 1. Who made whom`, then `### 1.1 ...` and `### 1.2 ...` under it. Write every list as a numbered list (`1.`, `2.`, `3.`), never with bullets. Tables number their rows in the first column. When you edit a page, renumber what follows the change. When you mention a part of a page, name it by its number, for example "neighbourhood 2.3".

This holds for pages written by hand. A generated page (`kind: generated`) gets its numbers from the script that writes it.

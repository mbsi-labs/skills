# Check the library first

Before you answer a question of fact, plan work, set a price or start research, search the library: `qmd search "<words>"`. Read the pages that match, answer from them, and name the pages you used.

If the library has nothing after a proper search (two or three phrasings), say so and file the gap for the research team in your ticket tracker. If you need the answer now, research it yourself with the do-research skill, which puts what you find back into the library.

A thanks, a relay, or a step that someone already chose needs no search.

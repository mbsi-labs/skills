# Custom CLIs

Custom CLIs give agents large gains. Use them and make them.

Before you do a task by hand, look for a CLI that does it. To learn how a CLI works, run `<name> help` or `<name> --help`. If no CLI does the task and the task will occur again, make a small CLI for it.

Look for CLIs in your shell's path and in the folder where you keep your own projects. If you keep tickets, notes and predictions in a CLI, use it, and keep it in your hand-off.

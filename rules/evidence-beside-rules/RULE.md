# Evidence goes beside a loaded file, not in it

A skill, rule, CLAUDE.md or brief loads into an agent's context in full, and every line of it reads as an instruction. Put only what helps with the task inside. Put evidence, credits, quotes and history in a file beside it that it does not load: a provenance file that the rule links to at its end, a `credits.md` in a skill folder, or the ticket.

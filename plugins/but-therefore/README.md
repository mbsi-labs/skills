# Turn a list of events into a story that people finish

By Mackenzie Bowes, with MBSI's agents.

Rebuilds a devlog or post as a chain of "but" and "therefore" instead of "and then".

What it can see: only the chat you add it to.

For your agent (the text it matches on): Build a story (a devlog, a post, a case study, a talk, a scene, a product story) as a chain of events joined by "but" and "therefore", never "and then". Use when outlining, drafting or editing any narrative, when turning a diary, transcript or commit history into a post, or when a draft reads like a list of things that happened.

## Install

### Claude Code

```
/plugin marketplace add mbsi-labs/skills
/plugin install but-therefore@skills
```

Later, `/plugin marketplace update` brings in changes.

### Claude apps (claude.ai and the desktop app)

Download https://mackenziebowes.com/skills/zips/but-therefore.zip, then upload it as a skill in Settings.

### ChatGPT or Grok

Open https://mackenziebowes.com/skills/text/but-therefore.txt, copy all of it, and paste it into a chat before your question.

# Dig: axioms, principles, cruxes

You failed because you believe something that is false. If you use more effort on the same belief, you will fail again.

1. Write what you did, and the result.
2. Write each thing that you thought was true, in three groups. Include the beliefs that seem too obvious to write.
   - Axioms: what you took as given.
   - Principles: the rules that you followed.
   - Cruxes: the beliefs that change what you do if they are wrong.
3. For each belief, ask: "What can show that this is false?" For a belief about the world, look at real examples, for example data or the material. For a belief about what the user wants, use the user's own words. Do not use only your memory.
4. Find the beliefs that failed. There can be more than one. Write each one.
5. Start again from the correct beliefs. Do not repair the old work.

Then show the user only the wrong beliefs and what you did with them. Do not show them the list.

If a wrong belief is about a fact in the world, test it: write down what you expect to see, then look.

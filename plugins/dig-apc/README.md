# Find the false belief behind a failure that keeps repeating

By Mackenzie Bowes, with MBSI's agents.

After a failure, it has your agent write what it did and what it believed, as axioms, principles and cruxes, then test each belief to find the one that is wrong.

What it can see: only the chat you add it to.

For your agent (the text it matches on): Dig on axioms, principles and cruxes (APC). This is the user's short word for: \"your thinking is shallow; find the belief that is wrong\". Use this skill when the user says \"dig-apc\", \"/dig-apc\" or \"examine your priors\", when the user rejects work and does not say why, and before you try again on anything that failed.

## Install

### Claude Code

```
/plugin marketplace add mbsi-labs/skills
/plugin install dig-apc@skills
```

Later, `/plugin marketplace update` brings in changes.

### Claude apps (claude.ai and the desktop app)

Download https://mackenziebowes.com/skills/zips/dig-apc.zip, then upload it as a skill in Settings.

### ChatGPT or Grok

Open https://mackenziebowes.com/skills/text/dig-apc.txt, copy all of it, and paste it into a chat before your question.

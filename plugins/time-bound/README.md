# Agents that work the whole hour — and don't lie about it

By Mackenzie Bowes, with MBSI's agents.

time-bound turns "spend 30 minutes on this" into six five-minute rounds, each ended by a reminder the agent can't talk itself out of, so it keeps picking the next piece until the last round hands you the write-up.

What it can see: only the chat you add it to.

For your agent (the text it matches on): Spend a set length of time on open-ended work that has no finish line (review a project, research a question, explore, play) with a countdown of reminders, one small checked piece per round, and a write-up shown at the last round. Use for /time-bound <minutes> <task>, or whenever you are told to spend a length of time on something.

## Install

### Claude Code

```
/plugin marketplace add mbsi-labs/skills
/plugin install time-bound@skills
```

Later, `/plugin marketplace update` brings in changes.

### Claude apps (claude.ai and the desktop app)

Download https://mackenziebowes.com/skills/zips/time-bound.zip, then upload it as a skill in Settings.

### ChatGPT or Grok

Open https://mackenziebowes.com/skills/text/time-bound.txt, copy all of it, and paste it into a chat before your question.

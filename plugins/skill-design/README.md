# Change your agent's behaviour with one small edit, not a long rulebook

By Mackenzie Bowes, with MBSI's agents.

A change to a skill, rule or hook ships only if it is small, one or two intentful edits, because every added line carries claims nobody checked.

What it can see: only the chat you add it to.

For your agent (the text it matches on): Change how Claudes behave through their environment (a skill, rule, CLAUDE.md, hook or brief) with the smallest change that research and a test show works. Use when making, editing or ratcheting a skill, rule, CLAUDE.md, AGENTS.md or hook, or when invoked as /skill-design.

## Install

### Claude Code

```
/plugin marketplace add mbsi-labs/skills
/plugin install skill-design@skills
```

Later, `/plugin marketplace update` brings in changes.

### Claude apps (claude.ai and the desktop app)

Download https://mackenziebowes.com/skills/zips/skill-design.zip, then upload it as a skill in Settings.

### ChatGPT or Grok

Open https://mackenziebowes.com/skills/text/skill-design.txt, copy all of it, and paste it into a chat before your question.

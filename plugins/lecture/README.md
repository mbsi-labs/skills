# Take the class before you do the work

By Mackenzie Bowes, with MBSI's agents.

Before work in a craft your agent hasn't studied, it gives the lecture a leading university would give on it, checks the claims and why they work, and writes the steps as a runbook its next session starts from.

What it can see: only the chat you add it to.

For your agent (the text it matches on): Learn a craft from the lecture a leading university would give on it, write what you learn as a runbook, and point your memory at it so the next session starts from it. Use for /lecture, 'what's the lecture', 'take the class on this', or before work in a craft you haven't studied (game balance, visual identity, pricing, SEO, a video, a cold email), or when your work keeps coming back generic.

## Install

### Claude Code

```
/plugin marketplace add mbsi-labs/skills
/plugin install lecture@skills
```

Later, `/plugin marketplace update` brings in changes.

### Claude apps (claude.ai and the desktop app)

Download https://mackenziebowes.com/skills/zips/lecture.zip, then upload it as a skill in Settings.

### ChatGPT or Grok

Open https://mackenziebowes.com/skills/text/lecture.txt, copy all of it, and paste it into a chat before your question.

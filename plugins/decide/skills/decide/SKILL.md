# Decide

The user judges results, not plans. So decide, then show them a short comparison of the outcome they can check.

1. **The question and its options.** Include doing nothing. The set of options is open: look for one you haven't thought of yet.
2. **For whom.** List the parties each option touches, for example the user, every Claude, a neighbour, a reader, et cetera.
3. **The door.** Is it cheap to undo (a two-way door, so decide now) or costly (a one-way door, which is the user's)? Say what undoing it would cost.
4. **Reward and cost for each party** for each option, including how sure you are of each.
5. **Pre-mortem.** Assume the choice failed a month from now. Write the most likely reason.
6. **The call.** Say which option, why, and what would make you revisit it.
7. **Show it** as one short table plus the call. Don't show the steps.

# Make the choice, then show the result, not the method

By Mackenzie Bowes, with MBSI's agents.

It compares the options for each person a choice affects, including doing nothing, then shows you a short result you can check.

What it can see: only the chat you add it to.

For your agent (the text it matches on): Make a decision by comparing options for each party they affect, then show the result rather than the method. Use when a choice has more than one reasonable option, when you're about to ask the user 'do you want X?', or when invoked as /decide.

## Install

### Claude Code

```
/plugin marketplace add mbsi-labs/skills
/plugin install decide@skills
```

Later, `/plugin marketplace update` brings in changes.

### Claude apps (claude.ai and the desktop app)

Download https://mackenziebowes.com/skills/zips/decide.zip, then upload it as a skill in Settings.

### ChatGPT or Grok

Open https://mackenziebowes.com/skills/text/decide.txt, copy all of it, and paste it into a chat before your question.

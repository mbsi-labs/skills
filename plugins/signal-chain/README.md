# Pick the format your reader can afford to take in

By Mackenzie Bowes, with MBSI's agents.

It ranks ways of carrying a message by how costly each is for the reader to decode, from faces and voices to writing and symbols, so you choose the one they can afford.

What it can see: only the chat you add it to.

For your agent (the text it matches on): Choose how to carry a message by how costly it is for the reader to decode, using the signal chain (emotions, physical narratives, speech, writing, symbols, and hostile signals that mimic a lower tier). Use when deciding whether to show or tell, picking a medium (video, demo, story, essay, docs, a chart), writing for a tired or broad audience, designing a page or a cognitive affordance, or working out why something true isn't landing.

## Install

### Claude Code

```
/plugin marketplace add mbsi-labs/skills
/plugin install signal-chain@skills
```

Later, `/plugin marketplace update` brings in changes.

### Claude apps (claude.ai and the desktop app)

Download https://mackenziebowes.com/skills/zips/signal-chain.zip, then upload it as a skill in Settings.

### ChatGPT or Grok

Open https://mackenziebowes.com/skills/text/signal-chain.txt, copy all of it, and paste it into a chat before your question.

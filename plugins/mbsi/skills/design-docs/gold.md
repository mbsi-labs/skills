# Gold: an explainer film

Gold is a design the person watches: the scenarios from a silver design acted out as an animated explainer, with the real types as the actors. Make one only when the person asks.

- Start from a finished silver design: the film shows its traces, it doesn't invent new ones.
- Animated explainer figures: draw animated SVG scenes for a passage, one per scenario.
- Video: any video tool you have, and price the run before you make it.
- Show it to the person inline, and record it on the ticket beside the design.

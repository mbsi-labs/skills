# Credits

The rule is Trey Parker and Matt Stone's, from a guest visit to an NYU class filmed for mtvU's "Stand In" (2011, from memory; check before citing in public): beats joined by "and then" are boring, beats joined by "therefore" or "but" are a story.

Mackenzie's framing (2026-10-15, to Rowan): "devlogs should be written as like... "I wanted this to exist so therefore I kicked off this process but it had this issue so therefore I had to create this solution for that but then this happened..." but / therefore chains between events, causal relationships."

The link to cheap decoding is Mackenzie's signal-chain model (see the `signal-chain` skill): physical narratives sit below verbal language.

Shape borrowed from Matt Pocock's writing skills (mattpocock/skills, `writing-beats`): the pile as a quarry, beats sized by what they need, gaps named instead of filled.

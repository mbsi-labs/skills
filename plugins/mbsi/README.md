# mbsi

By Mackenzie Bowes, with MBSI's agents.

All 15 MBSI skills in one plugin, so each one shows as mbsi:<name>.

## Install

```
/plugin marketplace add mbsi-labs/skills
/plugin install mbsi@skills
```

| Skill | What it does |
|---|---|
| mbsi:be-ambitious | Before your agent starts, it asks what the job is really for and what an expert would do, then asks for more than you first typed. |
| mbsi:but-therefore | Rebuilds a devlog or post as a chain of "but" and "therefore" instead of "and then". |
| mbsi:cognitive-prophylactics | Before you draft, it asks for one line: the situation your reader might meet and the move that lifts or lowers their standing in it. |
| mbsi:decide | It compares the options for each person a choice affects, including doing nothing, then shows you a short result you can check. |
| mbsi:dig-apc | After a failure, it has your agent write what it did and what it believed, as axioms, principles and cruxes, then test each belief to find the one that is wrong. |
| mbsi:encode-lessons | When the same correction comes up a second time, it picks the cheapest guard that holds it (a type, a lint rule, a hook or a script) instead of adding another line of text. |
| mbsi:eval-design | It turns 'is the agent better now?' into a question asked of many items of real work, with a named judge and a figure you can track. |
| mbsi:first-principles | When a rule changes, it redesigns the type model or module from the start instead of adding another special case. |
| mbsi:lever | When the work isn't trivial, it has your agent write the script that does it, rerun it on the first unit and diff the result against the hand version. |
| mbsi:prove-it | Before your agent says it is done, it runs the real program from outside and reads what it prints, instead of trusting a compile, a cached screenshot or its own word. |
| mbsi:scene-sections | It sets each generated scene behind its section's words, drawn for where those words go, with its own render for phones and desktops. |
| mbsi:signal-chain | It ranks ways of carrying a message by how costly each is for the reader to decode, from faces and voices to writing and symbols, so you choose the one they can afford. |
| mbsi:skill-design | A change to a skill, rule or hook ships only if it is small, one or two intentful edits, because every added line carries claims nobody checked. |
| mbsi:unblock | Your agent proceeds on reversible work, settles the mechanics itself and shows what it did and why, and still asks first about anything hard to reverse, outward-facing or costly. |
| mbsi:why-this-piece | Before you write, it asks four questions in writing: the point of the piece, why a reader would care, the business goal, and what making it says about us. |

# Get more from your agent than the first answer

By Mackenzie Bowes, with MBSI's agents.

Before your agent starts, it asks what the job is really for and what an expert would do, then asks for more than you first typed.

What it can see: only the chat you add it to.

For your agent (the text it matches on): Call this skill to discover more about your task.

## Install

### Claude Code

```
/plugin marketplace add mbsi-labs/skills
/plugin install be-ambitious@skills
```

Later, `/plugin marketplace update` brings in changes.

### Claude apps (claude.ai and the desktop app)

Download https://mackenziebowes.com/skills/zips/be-ambitious.zip, then upload it as a skill in Settings.

### ChatGPT or Grok

Open https://mackenziebowes.com/skills/text/be-ambitious.txt, copy all of it, and paste it into a chat before your question.

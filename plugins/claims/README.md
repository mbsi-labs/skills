# Number every claim so you can strike the wrong ones

By Mackenzie Bowes, with MBSI's agents.

It has your agent list every claim in a plan or sentence, the unstated ones first, numbered, so you can strike the wrong ones by number and it rebuilds from what's left.

What it can see: only the chat you add it to.

For your agent (the text it matches on): Call this skill to solve alignment incrementally. Use when the user says 'list every claim', 'list apc', 'read it back', or rejects work twice; when a belief you stated was called wrong; and before ratcheting anything into a rule.

## Install

### Claude Code

```
/plugin marketplace add mbsi-labs/skills
/plugin install claims@skills
```

Later, `/plugin marketplace update` brings in changes.

### Claude apps (claude.ai and the desktop app)

Download https://mackenziebowes.com/skills/zips/claims.zip, then upload it as a skill in Settings.

### ChatGPT or Grok

Open https://mackenziebowes.com/skills/text/claims.txt, copy all of it, and paste it into a chat before your question.

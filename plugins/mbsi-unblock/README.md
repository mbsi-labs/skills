# Keep your agent moving instead of asking about everything

By Mackenzie Bowes, with MBSI's agents.

Your agent proceeds on reversible work, settles the mechanics itself and shows what it did and why, and still asks first about what cannot be undone: deleting, spending money, or sending a message to a person outside the team.

What it can see: only the chat you add it to.

For your agent (the text it matches on): If you are about to ask a peer or human \"Should I do X,\" call this skill immediately. If you just asked a question about code, notes, tickets, branches, local config, publishing or deploying a page or post, names, conventions, or design and aren't getting an answer, call this skill.

## Install

### Claude Code

```
/plugin marketplace add mbsi-labs/skills
/plugin install mbsi-unblock@skills
```

Later, `/plugin marketplace update` brings in changes.

### Claude apps (claude.ai and the desktop app)

Download https://mackenziebowes.com/skills/zips/mbsi-unblock.zip, then upload it as a skill in Settings.

### ChatGPT or Grok

Open https://mackenziebowes.com/skills/text/mbsi-unblock.txt, copy all of it, and paste it into a chat before your question.

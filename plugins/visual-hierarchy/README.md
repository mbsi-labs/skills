# Decide what a screen shows first, second and last

By Mackenzie Bowes, with MBSI's agents.

Ranks everything on a screen by what matters to its person now, then makes the top ranks win with size, space, enclosure and position, not colour alone.

What it can see: only the chat you add it to.

For your agent (the text it matches on): Set the order in which a screen is seen (first, second, last) on purpose, before anyone looks at it. Use when designing, greyboxing or reviewing any page, app screen, dashboard or section; when a design "looks flat", "everything shouts" or ranks things by colour alone; when a list or history could grow long; and before showing a mockup to the person who decides.

# Build an article from the features that tested as wins

By Mackenzie Bowes, with MBSI's agents.

Gives each section of an article its one job (the reader's decision it serves) and lists the writing moves that held up in our tests, by kind of piece.

What it can see: only the chat you add it to.

For your agent (the text it matches on): The writing features that tested as wins, and what each section of an article is for. Use when writing or rewriting any post, article, research page or story, and when checking a draft.

## Install

### Claude Code

```
/plugin marketplace add mbsi-labs/skills
/plugin install writing-wins@skills
```

Later, `/plugin marketplace update` brings in changes.

### Claude apps (claude.ai and the desktop app)

Download https://mackenziebowes.com/skills/zips/writing-wins.zip, then upload it as a skill in Settings.

### ChatGPT or Grok

Open https://mackenziebowes.com/skills/text/writing-wins.txt, copy all of it, and paste it into a chat before your question.

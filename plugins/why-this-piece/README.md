# Know why a piece exists before you write it

By Mackenzie Bowes, with MBSI's agents.

Before you write, it asks four questions in writing: the point of the piece, why a reader would care, the business goal, and what making it says about us.

What it can see: only the chat you add it to.

For your agent (the text it matches on): Before writing any post, article, research page, figure, story or email, new or a rewrite, answer four questions about it. Use whenever writing work starts, including outreach and replies sent in the user's name, and when a draft is called bad or generic.

## Install

### Claude Code

```
/plugin marketplace add mbsi-labs/skills
/plugin install why-this-piece@skills
```

Later, `/plugin marketplace update` brings in changes.

### Claude apps (claude.ai and the desktop app)

Download https://mackenziebowes.com/skills/zips/why-this-piece.zip, then upload it as a skill in Settings.

### ChatGPT or Grok

Open https://mackenziebowes.com/skills/text/why-this-piece.txt, copy all of it, and paste it into a chat before your question.
